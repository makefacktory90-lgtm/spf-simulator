# ТЗ для Gemini: SPF Симулятор (HTML)

---

## ЧТО НУЖНО СДЕЛАТЬ

Создай одностраничный HTML-файл (index.html) — интерактивный SPF-симулятор.

---

## КОНЦЕПЦИЯ

Одно лицо девушки, разделённое пополам вертикальной линией:
- Левая половина: кожа С SPF-защитой
- Правая половина: кожа БЕЗ SPF-защиты

По центру — вертикальный слайдер-весы (как часы/циферблат). Пользователь двигает слайдер → возраст меняется → картинки меняются.

---

## МЕХАНИКА

### Слайдер (по центру экрана)
- Вертикальный слайдер или круглый циферблат (как часы)
- 4 позиции: 25 лет → 30 лет → 35 лет → 45 лет
- При движении слайдера картинки плавно меняются (crossfade)
- Анимация: плавный переход между возрастами (opacity transition)

### Левая половина (SPF)
- Показывает картинку из папки `images/spf/`
- Файлы: `spf-25.jpg`, `spf-30.jpg`, `spf-35.jpg`, `spf-45.jpg`
- Подпись сверху: "С SPF 50"

### Правая половина (без SPF)
- Показывает картинку из папки `images/no-spf/`
- Файлы: `no-spf-25.jpg`, `no-spf-30.jpg`, `no-spf-35.jpg`, `no-spf-45.jpg`
- Подпись сверху: "Без SPF"

### Разделительная линия
- Вертикальная линия по центру
- Можно перетаскивать влево-вправо (как в before/after сравнениях)
- Показывает больше одной или другой стороны

---

## ДИЗАЙН

### Стиль
- Минималистичный, чистый
- Фон: белый или очень светло-серый (#f5f5f5)
- Шрифт: Inter или системный sans-serif
- Акцентный цвет: коралловый (#FF6B6B) для элементов управления

### Лейаут (мобильный приоритет)
```
┌─────────────────────────────┐
│         SPF SIMULATOR       │
│    Что солнце делает с кожей│
├──────────┬──────────────────┤
│          │                  │
│  С SPF   │   Без SPF       │
│          │                  │
│  [ФОТО]  │   [ФОТО]        │
│          │                  │
├──────────┴──────────────────┤
│                             │
│     ◄── 25  30  35  45 ──► │
│         [СЛАЙДЕР]           │
│                             │
├─────────────────────────────┤
│                             │
│  Факт о SPF (меняется      │
│  с возрастом)               │
│                             │
└─────────────────────────────┘
```

### Элементы
- Заголовок: "SPF SIMULATOR" (крупно)
- Подзаголовок: "Что солнце делает с кожей"
- Слайдер возраста (по центру, под фото)
- Текущий возраст (крупная цифра)
- Факт о SPF (меняется при каждом возрасте)

## ФАКТЫ (меняются при скролле)

**25 лет:**
"Сейчас разницы нет. Но каждый день без SPF — это депозит в банк морщин."

**30 лет:**
"Первые пигментные пятна. 90% видимого старения кожи — от солнца, не от возраста."

**35 лет:**
"Без SPF кожа теряет коллаген в 3 раза быстрее. Морщины углубляются."

**45 лет:**
"20 лет без защиты. Пигментация, потеря упругости, сосудистые звёздочки. SPF мог бы это предотвратить."

---

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- Один HTML-файл (всё inline: CSS + JS)
- Адаптивный (мобильный + десктоп)
- Работает без сервера (открыть файл в браузере)
- Плавные анимации (CSS transitions)
- Touch-friendly (работает на телефоне)
- Картинки подгружаются из папок `images/spf/` и `images/no-spf/`

---

## БОНУСНЫЕ ФИЧИ (если сможешь)

1. **Before/After слайдер** — вертикальная линия, которую можно двигать влево-вправо, показывая больше одной стороны
2. **Анимация при первом открытии** — лицо сначала молодое, потом быстро стареет (wow-эффект)
3. **Кнопка "Поделиться"** — скриншот результата для Instagram Stories
4. **Звук** — тиканье часов при движении слайдера (опционально, можно выключить)
